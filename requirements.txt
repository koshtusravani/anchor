# --- Torch installation ---
# Torch is intentionally excluded from this file's default install.
# Install torch/torchvision/torchaudio separately with a build matching
# the target machine, before installing the rest of this file.
#
# GPU machine (CUDA 12.1):
#   pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#
# CPU-only local machine:
#   pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1
#
# xformers is excluded. Installing it via pip's default resolver previously
# downgraded torch to 2.4.0, breaking version alignment with torchvision/
# torchaudio. Reintroduce it later using a wheel matched explicitly to the
# training machine's torch build.
